# 安裝方式（使用 Vercel Skills CLI）：
```bash
# 安裝 Anthropic 官方全部 Skill（全局安裝）
$ npx skills add anthropics/skills -g
```
```bash
# 只安裝指定 Skill（推薦按需安裝）
$ npx skills add anthropics/skills@frontend-design -g
$ npx skills add anthropics/skills@mcp-builder -g
$ npx skills add anthropics/skills@skill-creator -g
```
> **提示**：`skill-creator` 是一個非常有趣的「元技能」—— 它的功能是幫你創建新的 Skill，如果你剛開始學習 Skill 開發，可以先安裝它，然後告訴 AI「幫我創建一個 XXX Skill」，它會按照標準規範幫你生成 SKILL.md 和目錄結構。
---
## 手動安裝（不使用 CLI）：
如果你不想用 `npx skills` 命令，也可以手動操作：
```bash
# 克隆官方倉庫到本地
$ git clone https://github.com/anthropics/skills.git
```
```bash
# 將需要的 Skill 目錄複製到你的項目中
$ cp -r skills/skills/frontend-design .claude/skills/
```

## 安裝方式：
```bash
# 安裝 Vercel 全部 Skill
$ npx skills add vercel-labs/skills -g
```
```bash
# 安裝 find-skills（推薦首先安裝，用于搜索發現其他 Skill）
$ npx skills add vercel-labs/skills@find-skills -g -y
```
> **提示**：`find-skills` 是一個「技能發現者」Skill —— 當你需要完成某個任務但不知道有沒有現成的 Skill 時，它會自動幫你搜索並推薦最合適的 Skill，**強烈建議首先安裝它**。
