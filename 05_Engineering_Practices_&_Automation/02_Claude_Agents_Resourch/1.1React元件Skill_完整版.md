# 4.3.2 實戰：創建一個 React 元件生成 Skill

> **需求**：每次創建新的 React 元件時，需要遵循統一的檔案結構和編碼規範。
> 我們來創建一個包含模板和驗證腳本的完整 Skill 包。

# React 元件生成器

## 輸入參數

| 參數 | 必填 | 預設值 | 說明 |
|------|------|--------|------|
| componentName | ✅ | — | PascalCase 格式，如 BookmarkCard |
| description | ✅ | — | 一句話說明元件功能 |
| hasProps | ❌ | true | 是否需要 Props 型別定義 |
| hasState | ❌ | false | 是否需要內部狀態管理 |

---

## 執行步驟

### 1. 創建目錄

src/components/{componentName}/

### 2. 生成檔案

參考 resources/template/ 中的模板，生成以下檔案：

- index.tsx        — 元件主體（參考 component.tsx.tpl）
- types.ts         — Props 型別定義（hasProps=true 時生成）
- {componentName}.test.tsx  — 單元測試骨架（參考 test.tsx.tpl）

> ⚠️ 模板是「參考樣式」，不是複製對象。
> AI 應根據模板的結構風格，結合使用者需求生成實際程式碼，
> 這比純文字描述更直觀，生成品質也更高。

### 3. 編碼規範

- 函式型元件 + TypeScript，禁止使用 any
- Props interface 命名：{componentName}Props
- 樣式使用 Tailwind CSS，禁止內聯 style
- 匯出方式：named export（非 default export）
- 每個元件頂部添加 JSDoc 註解說明元件功能

### 4. 測試規範

- 使用 @testing-library/react
- 必須包含：渲染測試 + Props 傳遞測試

### 5. 驗證結構

創建完成後執行驗證腳本，確認檔案結構完整：

  node .claude/skills/react-component/scripts/validate.js {componentName}

## Step 3：創建輔助腳本（scripts/）

創建 `.claude/skills/react-component/scripts/validate.js`：

```javascript
#!/usr/bin/env node
// scripts/validate.js — 驗證元件目錄結構是否完整
// AI 在執行 Skill 後可執行此腳本進行自檢

const fs = require('fs');
const path = require('path');

const componentName = process.argv[2];

if (!componentName) {
  console.error('用法: node validate.js <ComponentName>');
  console.error('範例: node validate.js BookmarkCard');
  process.exit(1);
}

function validateComponent(componentName) {
  const dir = path.join('src/components', componentName);
  const requiredFiles = ['index.tsx', 'types.ts', `${componentName}.test.tsx`];
  const missing = [];

  // 檢查目錄是否存在
  if (!fs.existsSync(dir)) {
    console.error(`❌ 目錄不存在: ${dir}`);
    process.exit(1);
  }

  console.log(`\n📁 檢查 ${dir}/`);

  // 檢查必要檔案
  requiredFiles.forEach(file => {
    const fullPath = path.join(dir, file);
    if (!fs.existsSync(fullPath)) {
      missing.push(file);
    } else {
      console.log(`  ✅ ${file}`);
    }
  });

  // 檢查 index.tsx 內容規範
  const indexPath = path.join(dir, 'index.tsx');
  if (fs.existsSync(indexPath)) {
    const content = fs.readFileSync(indexPath, 'utf-8');
    const checks = [
      { rule: content.includes('export function'), msg: '使用 named export' },
      { rule: !content.includes(': any'),          msg: '無 any 型別' },
      { rule: !content.includes('style={{'),       msg: '無內聯 style' },
    ];
    console.log('\n  📋 程式碼規範檢查：');
    checks.forEach(({ rule, msg }) => {
      console.log(`  ${rule ? '✅' : '⚠️ '} ${msg}`);
    });
  }

  if (missing.length > 0) {
    console.error(`\n❌ 缺少以下檔案：`);
    missing.forEach(f => console.error(`   - ${f}`));
    process.exit(1);
  }

  console.log(`\n🎉 元件 ${componentName} 結構驗證通過！`);
}

validateComponent(componentName);
```

## Step 4：創建程式碼模板（resources/template/）

### component.tsx.tpl

```tsx
/**
 * {componentName} 元件
 * {description}
 */

import { {componentName}Props } from './types';

export function {componentName}({ ...props }: {componentName}Props) {
  return (
    <div className="...">
      {/* 元件內容 */}
    </div>
  );
}
```

### types.ts.tpl

```typescript
export interface {componentName}Props {
  // 在此定義元件的 Props
  className?: string;
  children?: React.ReactNode;
}
```

### test.tsx.tpl

```tsx
import { render, screen } from '@testing-library/react';
import { {componentName} } from './index';

describe('{componentName}', () => {
  it('渲染不報錯', () => {
    render(<{componentName} {/* 傳入必要的 Props */} />);
  });

  it('正確展示傳入的 Props', () => {
    // 根據實際 Props 補充斷言
  });
});
```

> 💡 **設計要點**：`.tpl` 後綴明確表示這是「模板」，不是可執行程式碼，
> 避免 AI 或開發者誤把模板當實際檔案使用。

### BookmarkCard-example/index.tsx

```tsx
/**
 * BookmarkCard 元件
 * 展示單個書籤的卡片，顯示標題、URL、描述和標籤列表
 */

import { BookmarkCardProps } from './types';

export function BookmarkCard({
  title,
  url,
  description,
  tags = [],
  className = '',
}: BookmarkCardProps) {
  const hostname = new URL(url).hostname;

  return (
    <div className={`rounded-xl border border-gray-200 bg-white p-4 shadow-sm hover:shadow-md transition-shadow ${className}`}>
      <div className="mb-2">
        <h3 className="text-base font-semibold text-gray-900 truncate">{title}</h3>
        <a
          href={url}
          target="_blank"
          rel="noopener noreferrer"
          className="text-xs text-blue-500 hover:underline truncate block"
        >
          {hostname}
        </a>
      </div>

      {description && (
        <p className="text-sm text-gray-500 mb-3 line-clamp-2">{description}</p>
      )}

      {tags.length > 0 && (
        <div className="flex flex-wrap gap-1">
          {tags.map(tag => (
            <span key={tag} className="px-2 py-0.5 text-xs bg-gray-100 text-gray-600 rounded-full">
              #{tag}
            </span>
          ))}
        </div>
      )}
    </div>
  );
}
```

### BookmarkCard-example/BookmarkCard.test.tsx

```tsx
import { render, screen } from '@testing-library/react';
import { BookmarkCard } from './index';

const defaultProps = {
  title: 'Tailwind CSS 官方文件',
  url: 'https://tailwindcss.com',
  description: '一個實用優先的 CSS 框架',
  tags: ['css', 'frontend'],
};

describe('BookmarkCard', () => {
  it('渲染不報錯', () => {
    render(<BookmarkCard {...defaultProps} />);
  });

  it('正確顯示標題', () => {
    render(<BookmarkCard {...defaultProps} />);
    expect(screen.getByText('Tailwind CSS 官方文件')).toBeInTheDocument();
  });

  it('正確渲染標籤列表', () => {
    render(<BookmarkCard {...defaultProps} />);
    expect(screen.getByText('#css')).toBeInTheDocument();
  });

  it('沒有 description 時不渲染描述區域', () => {
    render(<BookmarkCard title="Test" url="https://example.com" />);
    expect(screen.queryByRole('paragraph')).not.toBeInTheDocument();
  });
});
```

## 設計要點回顧

| 設計決策 | 原因 |
|----------|------|
| `.tpl` 後綴 | 明確區分「模板」與「實際程式碼」，避免誤用 |
| `examples/` 真實範例 | 比純文字規範更直觀，AI 生成品質更高 |
| `named export` 規範 | 統一匯出方式，便於 tree-shaking 和 IDE 跳轉 |
| `validate.js` 自檢 | AI 可在生成後立即自我驗證，無需人工逐個檢查 |
| description 寫觸發短語 | 明確告訴 Claude 何時觸發，減少漏觸發 |
| 表格化輸入參數 | 比列表更清晰，AI 解析準確率更高 |
